# 高跟踩蚂蚁

手机网页小游戏：踩扁成群的蚂蚁。两种操控：按住蓄力、松手踩下；或者让脚跟着手指走，放到地上压住，再往下按加力碾死。纯 HTML + Canvas，不需要构建，静态托管即可运行。只支持横屏：手机或平板竖着拿时会显示“请把手机横过来”，正在进行的一局自动暂停，横过来点“继续”接着玩（添加到主屏幕后在安卓上会直接锁定横屏）。

## 玩法

有两种操控方式，在"设置"里的"操控"切换（会记住你的选择）。

所有设置都收在主菜单和暂停菜单的"设置"里：声音、震动、操控、粘鞋（拖动压时才出现）、外观、跨度限制、全屏（浏览器支持时）。"返回"回到打开它的菜单。

**蓄力踩**（默认）

| 操作 | 效果 |
| --- | --- |
| 按住屏幕 | 抬脚、显示落点阴影，压力条开始蓄力（约 0.85 秒蓄满）。蓄力就是把脚越抬越高，姿势跟拖动压的高度分区一样：低处翘起露出红鞋底（`05`）→ 中间鞋底放平朝下（`09`）→ 蓄满时最高、脚尖朝下（`01`） |
| 拖动 | 移动落点（上下拖动改变前后深度） |
| 松手 | 踩下（下落途中按高度换回中间、低处的姿势）。压力越大范围越大；蓄满时为"满压"，震晕周围蚂蚁、地面开裂 |

**拖动压**

| 操作 | 效果 |
| --- | --- |
| 按住拖动 | 脚跟着手指走（手指握在腿上，鞋底在手指下方一段，不会挡住蚂蚁）。往下按的位置整体偏高：踩满的位置最多在屏幕高度的 80%，并且离底边至少约 80 像素，手指不用拖到屏幕边上（iPhone/iPad 上从底边往上划会退出浏览器）。从落地到踩满的下拉距离和原来一样（110 个游戏单位：手机上约 60–85 像素，iPad 上约 170 像素） |
| 抬脚高度分三区 | 从高到低：脚尖朝下的侧面（`01`）→ 鞋底放平朝下（`09`）→ 翘起露出红鞋底（`05`）。长靴和黑丝用同一套分区。最高只到鞋底离屏幕顶约 42% 的位置，整只脚都在画面里 |
| 鞋底碰到地面 | 换成站姿（`stand_0`）。脚下的蚂蚁被压住，先不死，只会挣扎尖叫，压力条旁显示"压住 ×N"。往下按得越重，被压住的蚂蚁叫得越响、越密，挣扎得越厉害，头上的感叹号从“!”变成“!!”“!!!”。鞋直接放在后脚身上时，前脚就站在后脚前面，后脚不挪；放得离后脚太远（超过 1.35 个鞋长），后脚会跟上来 |
| 继续往下按 | 压力分区：35% 时后脚开始把重心往前压（`04_boot`），70% 时后脚扭到底（`08_boot`），同时压住的蚂蚁全部被踩扁；按到底是满压 |
| 往上拖 / 松手 | 抬脚（鞋底要离地 5px 以上才算抬起，手指轻微抖动不算）。没被踩死的蚂蚁会逃走，压力超过 30% 的话会受伤。松手时脚在空中，就平稳落回地面站着，落地时有鞋跟落地的声音 |
| 按着在地上左右拖 | 碾：手指要横着拖过约 14 像素（20 个游戏单位）才开始，往下按时手指的小幅晃动不算；开始后鞋压着慢慢滑，停住约 0.25 秒就不碾了。往后脚那边拖时，鞋直接从后脚前面滑过去（后脚站得更靠后，画面上是两条腿交叉而过），后脚原地不动，不会卡，在屏幕边上也一样。压力在致死线以上时，滑过去的蚂蚁也会被碾死（不计入"单脚"纪录）；松到致死线以下就只是挡住它们 |

**粘鞋**（只在拖动压模式下，"设置"里有"粘鞋：开/关"）：每次踩死蚂蚁，有 30% 的概率这一脚会粘鞋，其中几只（2–6 只）粘在鞋底，鞋底和正下方的地面之间拉出拉丝，丝上还可能吊着蚂蚁。往上抬脚时会被拽住，脚跟不上手指。继续用力往上拖，丝会一根根崩断（每根 +2 自尊），最后一根断开时显示"拽开!"。抬起来能看到红鞋底上糊着残骸，几秒后慢慢掉落；每根丝都是从鞋底上那只踩扁的蚂蚁身上拉出来的。鞋抬在空中时红鞋底对着镜头，丝画在鞋子前面；压在地上（侧面看不到鞋底）时丝在前脚后面。丝挂在前脚底下，所以永远在后脚前面。丝的最大长度比被拽住时鞋能抬到的高度短一点，直着往上拉一定能拉断。

**站姿**：街道比一步宽得多。"设置"里的"跨度限制"打开时（默认），抬起的脚离站着的脚最远 3.5 个鞋长（蓄力踩的落点、拖动压跟手的鞋、碾都一样）；iPad 横屏整条街本来就在这个范围内，不会被卡住，更宽的手机横屏才会限制。关掉后抬起的脚可以伸到任何地方。不管开不开，落地后两脚相距超过 1.35 个鞋长，后脚都会跟上来迈到前脚旁边，所以走到街道另一头是一步一步走过去的。

**两种方式通用**

| 操作 | 效果 |
| --- | --- |
| 碾 | 蓄力踩：按住街道上方的腿，左右拖动碾过去。拖动压：鞋按在地上时左右拖。碾的时候压力会往上走（蓄力踩按住越久越大，拖动压看往下按的深度），另一只脚和往下压的时候共用同一套分段：35% 起把重心往前压（`04`），70%（致死线）起脚跟翘起来（`08`），鞋尖始终踩在地上 |
| 暂停按钮 / Esc | 暂停，可结算、重开、切换操控 |

计分（"自尊"）：

- 惊慌尖叫中的蚂蚁 ×2（惨叫中断）
- 受伤爬行的蚂蚁 ×1.5（补刀清理）
- 鞋跟正好扎到 ×3（鞋跟暴击）
- 满压击杀 ×2
- 连杀每 10 只额外 +50%

打破个人纪录时，左上角会弹出 `+N 纪录名`。纪录保存在浏览器本地（localStorage）。

模式：**60 秒挑战**，或者**无尽解压**（随时从暂停菜单结算）。

## 本地运行

ES 模块不能通过 `file://` 加载，需要起一个静态服务器：

```bash
python3 -m http.server 8000
# 手机和电脑在同一个 Wi-Fi 下时，用 http://<电脑IP>:8000 访问
```

### 部署到 GitHub Pages

仓库里带了部署流程 `.github/workflows/pages.yml`：每次推送到默认分支，都会用 `tools/build_site.sh` 打包游戏运行需要的文件（两套外观一共约 1.5MB，不含 `assets/source` 里的原始高清素材和工具脚本），然后发布到 GitHub Pages。打包时会给网页脚本、样式表、每个模块和每张图片的地址加上这次提交的版本号（`?v=...`），所以每次部署后浏览器都会拿到新文件，不会新旧混用。

第一次需要在仓库里手动开启一次：**Settings → Pages → Build and deployment → Source 选 “GitHub Actions”**。之后到 **Actions** 页重新运行一次 “Deploy to GitHub Pages”（或者再推送一次）。网址是：

```
https://<用户名>.github.io/<仓库名>/
```

注意：私有仓库要开 GitHub Pages，需要 GitHub Pro 或团队版。免费账号得把仓库改成公开才行（网站本身无论如何都是公开的）。

想部署到别的静态托管（Netlify、Cloudflare Pages 等），运行 `tools/build_site.sh`，把生成的 `_site` 目录发布出去即可。iOS Safari 不支持网页全屏 API，可以用"分享 → 添加到主屏幕"，以全屏 App 的方式运行。

## 素材

高跟鞋和角色头像来自原作者提供的高清素材，透明背景由作者手工抠好，已获原作者授权在本项目中使用。如果要公开发布或商用，请再向原作者确认授权范围。

有两套外观，姿势、顺序完全一样，在"设置"里的"外观"切换（会记住选择，另一套在后台预加载）。两套原图画的都是整条腿（过膝漆皮长靴 / 黑丝配高跟鞋），屏幕上露出来的小腿、膝盖都是画出来的：

| 外观 | 原图 | 游戏用的精灵 |
| --- | --- | --- |
| 长靴 | `assets/source/hd/NN_boot.png` | `assets/sprites/hd/` |
| 黑丝 | `assets/source/stockings/NN_stocking.png` | `assets/sprites/stockings/` |

两套共用 `assets/source/hd/` 里的头像。

`tools/extract_hd.py` 负责处理每一套素材（新加一套只要在脚本的 `SKINS` 里加一行）：
- 裁掉空白；按站姿那张的鞋长统一缩放，让鞋长约 355 像素（脚和原来一样清晰）；只保留最低点往上 3 个鞋长的腿（屏幕上最多露出约 2.6 个鞋长），再往上的大腿裁掉；转成 WebP（每张约 40 KB）
- 算出每帧的鞋尖、鞋跟尖、红色鞋底中心、脚的中心、腿在街道上方露出那段的左右范围（蓄力踩“按住腿碾”的判定区）和最上面一行"拉伸行"（万一腿露到裁剪线以上，就把这一行往上拉长补齐，正常情况下用不到），写进各自目录下的 `sprites.json`

游戏里用这些锚点决定踩踏范围、落地对齐，以及把腿向上延伸出屏幕。更换素材后重新运行：

```bash
pip install pillow numpy scipy
python3 tools/extract_hd.py --preview /tmp/preview.jpg
```

如果某帧缺少必需的锚点，游戏会在加载时直接报错，不会进到一半卡死。

头像有两张：平时是粉衣（`12_green_portrait`），连杀时（连续踩死 2 只以上，左上角显示“连杀 ×N”）或者拖动压压住蚂蚁时，渐变成红衣（`13_red_portrait`）；两者都结束后 1.5 秒内没有再出现，就切回粉衣。

背景城市、蚂蚁、界面和音效都是代码生成的，没有使用其他素材。踩踏声按真实高跟鞋录音合成（3 段 CC0 录音里挑出的 9 下脚步，只用来测量，没有放进游戏）：一下约 10 毫秒、起音约 1 毫秒的"哒"，能量集中在 0.5–2 kHz，没有音调，也没有低频闷响；街道一点点偏暗的余音；约 100 毫秒后鞋底着地，比鞋跟弱约 9 dB（真实录音是 6–9 dB）。各项参数是把合成声和录音的各频段能量、频谱重心、衰减、起音时间、鞋底那一下的音量直接拟合出来的（每组参数取 32 下的平均，避免只对某一段噪声凑数）。踩得越重，多一点中低频的分量。只有蚂蚁真的被踩死才有碾碎声：拖动压过致死线时脚下没有蚂蚁就不出声，满压（两种操控）也不再额外响提示音；蓄力踩蓄满时的提示音保留，用来提示松手时机。WebP 需要 iOS 14 / Safari 14 及以上。
